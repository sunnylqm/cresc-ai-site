    环境检查(通用步骤)#

    #（1）确认Nodejs环境已安装

    1. 在windows或MacOS终端输入以下命令
    npm list -g --depth-0

    正常情况应该是如下图所示（没有任何内容也没关系），如果提示“命令未找到”，则说明你没有安装Nodejs，你需要按 此教程 来安装运行Claude Code、Codex、Gemini等CLI所需的环境

    1. 如果你发现自己没有安装Nodejs，并且跟着教程目前已经安装完毕，请你重新执行上述提到的命令，如果不再提示“命令未找到”，则说明安装成功

    #（2）安装CLI

    1. 在windows或MacOS终端输入以下命令，一次性安装好我们目前所需的所有终端
    npm i -g @anthropic-ai/claude-code@latest
npm i -g @openai/codex@latest
npm i -g @google/gemini-cli@latest

    1. 如果你还需要使用 Grok Build，请根据系统执行对应的官方安装命令
    Windows
    MacOS / Linux / WSL
    irm https://x.ai/cli/install.ps1 | iex
    curl -fsSL https://x.ai/cli/install.sh | bash

    #（3）测试安装成功

    IMPORTANT

    这一步很重要，请你务必运行命令进行测试，因为这一步运行命令后，你的用户目录下才会生成各CLI的配置目录，方便后续操作！

    Claude Code
    Codex
    Gemini
    Grok Build
    1. 在windows或MacOS终端输入以下命令，若出现图示内容，或出现选项让你选择，则Claude code安装成功
    claude

    IMPORTANT

    第二步十分重要，请你务必跳转链接后运行命令进行配置

    1. 点击 claude code 无法连接到 Anthropic 服务 跳转，务必根据教程运行命令，然后再继续阅读之后单独CLI的配置教程

    在windows或MacOS终端输入以下命令，若出现图示内容，或出现选项让你选择，则Codex安装成功

    codex

    在windows或MacOS终端输入以下命令，若出现图示内容，或出现选项让你选择，则Gemini安装成功

    gemini

    在windows或MacOS终端输入以下命令，若输出版本号，则Grok Build安装成功

    grok --version
