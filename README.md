# Cresc AI Documentation Site

This repository contains the documentation site for Cresc AI, built using [Rspress](https://rspress.dev/).

## Structure

- `site/`: The Rspress project directory
  - `pages/`: Documentation pages in MDX format
  - `components/`: React components for dynamic pages
  - `styles/`: Stylesheets

## Development

To run the site locally in development mode:

```bash
cd site
npm install
npm run dev
```

To build the static site:

```bash
cd site
npm run build
```
