## 价格是怎么算出来的

页面上的价格全部来自本站计费配置，实时同步，不是手工维护的静态表格。价格单位统一为**每百万 token**。

1. **原价**（划线的 `$` 价）：模型的官方参考价，以美元计。
2. **计费倍率**：每个令牌分组有各自的倍率，例如 `0.8` 倍 = 8 折，`0.5` 倍 = 5 折。
3. **实付价**（加粗的 `¥` 价）= 原价 × 该分组的计费倍率，再按站点汇率折算成人民币，也就是你真正会被扣掉的金额。

::: info 关于汇率
本站账户余额以美元额度记账，充值 1 元人民币到账 1 美元额度，因此实付人民币金额与美元额度是 1:1 的。
汇率同样由接口下发，调整后页面会自动跟随，无需改动文档。
:::

::: tip 倍率怎么看
- 倍率 `< 1`：享折扣，绿色显示，例如 `0.5x` 表示 5 折
- 倍率 `= 1.0`：按原价计费
- 倍率 `> 1`：加价渠道，橙色显示，通常对应稳定性更高或限制更严格的专属号池
:::

## 如何选择令牌分组

1. 在上方的**分组总览**里点击任意分组卡片，即可只看该分组下的模型与价格；也可以用搜索框直接搜模型 ID。
2. 选定分组后，在控制台创建 API 令牌时选择同一个分组。
3. 使用 Claude Code、Codex 或 Gemini CLI 时，请确认选择对应工具支持的分组，避免因模型不存在或分组不匹配导致报错。

::: warning 说明
- 表格只展示 token 计费项（输入 / 输出 / 缓存读）。缓存写入、图片与视频生成、联网搜索等固定计费项以控制台账单为准。
- 少数已下线的旧版本模型在官方定价表中已被移除，原价显示为 “-”，但仍可正常调用。
:::
